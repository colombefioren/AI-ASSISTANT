# Avatar credits

Both avatars come from the example set of [TalkingHead](https://github.com/met4citizen/TalkingHead)
by Mika Suominen. They were re-encoded for the web with
[glTF Transform](https://gltf-transform.dev) (WebP textures at 1024 px, meshopt geometry
compression). Geometry, rig and blend shapes are unchanged.
